# ☕ Cafe Ordering System

A lightweight, interactive cafe ordering web application built using HTML, CSS, and Vanilla JavaScript. Users can browse the cafe menu, add multiple items, adjust quantities, and view a real-time order summary with instant checkout.

## 🚀 Features

- **Interactive Menu:** Browse items (Pizza, Pasta, Burger, Coffee, etc.) with listed prices.
- **Dynamic Cart:** Add, increment, decrement, and remove items on the fly.
- **Real-Time Billing:** Automatically calculates subtotal, taxes, and final payable amount.
- **Receipt Generation:** Simple checkout modal displaying the complete order summary.
- **Responsive Layout:** Works cleanly across desktop and mobile screens.

## 🛠️ Built With

- HTML5
- CSS3 / Tailwind CSS
- Vanilla JavaScript
